⚡ Canon F-789SGA Vector Mode Setup & Commands

Enter Vector Mode & Store Vectors:

  • • MODE 8 (VECTOR)
  • • Apps 1 (VctA) → 1 (3D) or 2 (2D)
  • • Enter components, then press AC
  • • To edit/store VctB/C: Apps 2 (Data) → select VctB or VctC

Key Vector Operations:

  • • Dot Product: Apps 3 (VctA) Apps 8 (Dot) Apps 4 (VctB)
  • • Cross Product: Apps 3 (VctA) × Apps 4 (VctB)
  • • Vector Magnitude |V|: SHIFT hyp (Abs) Apps 3 (VctA)
  • • Unit Vector û: Apps 3 ÷ SHIFT hyp Apps 3

🌐 Coordinate Conversions & Canon Pol() / Rec() Traps

Cartesian (x,y,z) ↔ Cylindrical (ρ,φ,z)

z remains identical. Convert (x,y) via calculator:

• SHIFT + (Pol) x, y → r = ρ, θ = φ (Auto Quadrants!)

• SHIFT - (Rec) ρ, φ → X = x, Y = y

Spherical (r,θ,φ) ↔ Cylindrical (ρ,φ,z)

φ stays unchanged. Convert (r,θ) via Rec:

• SHIFT - (Rec) r, θ → X = z and Y = ρ

⚠️ BOARD TRAP: Calculator outputs X first (which is z) and Y second (which is ρ). Write Cylindrical as (ρ, φ, z) = (Y, φ, X)!

∇ Del Operators Core Rules

Gradient ∇f

Scalar → Vector

∇f = (∂f/∂x)i + (∂f/∂y)j + (∂f/∂z)k

Directional Derivative: D_u f = ∇f · û

Divergence ∇ · F

Vector → Scalar

∇·F = ∂Fx/∂x + ∂Fy/∂y + ∂Fz/∂z

∇ · F = 0 → SOLENOIDAL (Divergence-free)

Curl ∇ × F

Vector → Vector

Determinant of [i j k; ∂/∂x ∂/∂y ∂/∂z; Fx Fy Fz]

∇ × F = 0 → IRROTATIONAL

📜 The 3 Integral Theorems of Vector Calculus

Stokes' Theorem

Connects Line Integral & Surface Integral:

∮_C F · dr = ∬_S (∇ × F) · dS

Green's Theorem

2D Planar case of Stokes':

∮_C (P dx + Q dy) = ∬_D (∂Q/∂x - ∂P/∂y) dA

Gauss Divergence Theorem

Connects Surface Integral & Volume Integral:

∬_S F · dS = ∭_V (∇ · F) dV

⚠️ Board Exam Classic Distractor: Kennedy's theorem is for kinematics of machinery (instantaneous centers), NOT vector calculus!
