Pre-Exam Active Recall Cheat Sheet

1. Vector Operations & Products

  • Dot Product (A·B): Commutative (A·B = B·A), scalar output. Result is 0 when vectors are perpendicular (90°). $\cos\theta = (A\cdot B)/(|A||B|)$.
  • Cross Product (A×B): Anti-commutative ($A\times B = -(B\times A)$), vector output perpendicular to both. $|A\times B| = |A||B|\sin\theta$. Max at 90°, 0 at 0°/180°.
  • Lagrange Identity: $|A\times B|^2 + |A\cdot B|^2 = |A|^2|B|^2$. Perfect calculator shortcut!

2. Canon F-789SGA Coordinate Conversions

  • Floor Triangle (x,y) ↔ (ρ,φ): Use Pol(x,y) $\to r=\rho, \theta=\varphi$. Use Rec(ρ,φ) $\to X=x, Y=y$.
  • Wall Triangle (z,ρ) ↔ (r,θ): Use Pol(z,ρ) $\to r=r, \theta=\theta$. Use Rec(r,θ) $\to X=z, Y=\rho$.
  • Trap Warning: Canon F-789SGA outputs $X=z$ and $Y=\rho$ for spherical conversions! Always swap order for $(\rho, \varphi, z)$.

3. Vector Differential Operators (Del ∇)

  • Gradient (∇f): Scalar field $\to$ Vector field. Points in direction of maximum rate of change.
  • Divergence (∇·F): Vector $\to$ Scalar. $\nabla\cdot F = \frac{\partial F_x}{\partial x} + \frac{\partial F_y}{\partial y} + \frac{\partial F_z}{\partial z}$. If $\nabla\cdot F = 0$, field is solenoidal / divergence-free.
  • Curl (∇×F): Vector $\to$ Vector. Evaluated via $3\times3$ determinant. If $\nabla\times F = 0$, field is irrotational.
  • Directional Derivative: $DD = \nabla f \cdot \hat{u}$ where $\hat{u} = \vec{v}/|\vec{v}|$.

4. Integral Theorems & Traps

  • Stokes' & Green's Theorem: Connects Line Integral ($\oint F\cdot dr$) $\longleftrightarrow$ Surface Integral ($\iint (\nabla\times F)\cdot dS$).
  • Gauss Divergence Theorem: Connects Closed Surface Integral ($\iint F\cdot dS$) $\longleftrightarrow$ Volume Integral ($\iiint \nabla\cdot F \,dV$).
  • Board Exam Trap: Kennedy's Theorem belongs to Kinematics / Machines, NOT vector calculus!

1. Linearity & Red Flag Rules

  • Order: Highest order derivative present. Degree: Exponent of highest derivative.
  • Non-Linear Red Flags (ANY = Non-linear):
    • Exponent of $y$ or any derivative $\neq 1$ (e.g., $y^2$, $(y'')^2$).
    • $y$ inside non-linear function (e.g., $\sin y$, $e^y$, $\ln y$).
    • Product of $y$ and its derivative (e.g., $y y'$, $y \frac{dy}{dx}$).
  • Functions of independent variable $x$ (like $\sin x$, $e^x$) do NOT break linearity!

2. Higher-Order ODE Roots (Mode 5-3 / 5-4)

  • Case 1 (Distinct Real $a, b$): $y = C_1 e^{ax} + C_2 e^{bx}$.
  • Case 2 (Repeated Real $a, a$): $y = C_1 e^{ax} + C_2 x e^{ax}$.
  • Case 3 (Complex Conjugate $a \pm bi$): $y = e^{ax}(C_1 \cos bx + C_2 \sin bx)$.
  • Use Canon F-789SGA Mode 5-3 (Quadratic) or Mode 5-4 (Cubic) to find roots directly!

3. Exponential Applications (Mode 3-6)

  • Growth / Decay / Half-Life: Input $(x_1, y_1)$ and $(x_2, y_2)$ into Mode 3-6 ($A\cdot B^X$). Predict using x̂ (given $y$) or ŷ (given $x$).
  • Newton's Cooling Law: Enter $Y = |T - T_s|$ (Difference from ambient temperature). Then $T(t) = T_s \pm \hat{y}$.
  • Brine Mixing: $\frac{dQ}{dt} = R_{in}C_{in} - R_{out}\left(\frac{Q}{V_0 + (R_{in}-R_{out})t}\right)$. Integrated directly.

4. Laplace Transform Caltech Technique

  • Caltech Laplace Shortcut: Set $s = 10$, $\infty = 15$.
  • Compute numerical integral: $\int_{0}^{15} f(t) e^{-10t} dt$ in Mode 1.
  • Substitute $s = 10$ into options A, B, C, D to find exact numerical match!
  • Convolution: $(f*g)(t) = \int_0^t f(\tau)g(t-\tau)d\tau$. Evaluate integral at $t=5$ to match choices.
